# Safety and security scope

This is a computational research demonstrator. It is not safe to attach to industrial pumps, chemical dosing skids, wafer-processing equipment, or other consequential control systems. No hardware or wet-chemistry procedures have been validated here. Any physical experimentation requires a qualified institution's safety review and authorized equipment.

The public repository contains no intended credentials, deployment keys, API tokens, signing private keys, or proprietary model weights. Please do not attach sensitive information, private lab data, proprietary process parameters, or credentials when reporting issues. Open public GitHub issues for reproducibility or scientific criticism; handle sensitive security matters through the repository's GitHub private vulnerability reporting feature if enabled.
