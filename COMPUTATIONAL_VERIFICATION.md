This research repository reports a **computational candidate only**. No instrument has been fabricated, no native KiCad ERC or foundry-specific DRC has passed, and no wet-lab measurement exists.

- Release source: OTDB-APW Rev D, research candidate v0.4.0-rc4; publication-cleaned from the original computational release without changing the scientific algorithms, C99 firmware code, or reference numerical data.
- Local audit date: 2026-11-15.
- Independent clean-extract command: `bash ./REPRODUCE_OTDB_APW_RELEASE_004.sh`.
- Result: exit 0; 6/6 standard Python tests passed; 6/6 `python3 -O` tests passed; 7/7 generated JSON comparison reports regenerated byte-for-byte; immutable manifest entries unchanged.
- Verified run environment: Python 3.13.5, NumPy 2.3.5, SciPy 1.17.0, Matplotlib 3.10.8, Shapely 2.1.2 and a system C compiler. `requirements.txt` pins a separate supported set for portable reproduction; this local audit did not install those exact pinned versions.
- Missing native engineering validation: `kicad-cli` was not installed in the audit environment. The programmatic schematic checks are a prototype verification, not a substitute for native KiCad ERC or physical electronics testing.
- Two scientific limitations deliberately preserved: in synthetic scenario S1 a conventional calibrated multi-sensor baseline wins (0.67% vs 3.96% mean error); in synthetic reference-fouling scenario NC5 the proposed instrument has a 71.17% mean estimation error **without an alarm**. A proposed fault-screen patch exists outside this release but has not been hardware qualified and is not claimed as a fix here.
- Scientific references: Nassr et al. (2025) are cited as external prior-art motivation, **not** as independent evaluation of this sensor. Cahill's 1990 3ω primary method citation is verified as DOI `10.1063/1.1141498`.
