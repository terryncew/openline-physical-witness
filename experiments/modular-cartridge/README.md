# Modular wet-side cartridge: scaling-reduction experiment

**Status: ENGINEERING DESIGN REVIEW ONLY · hardware and production readiness HOLD**

This is the next bounded investigation after [004's computational research](../../README.md), [005's benchtop feasibility](../benchtop-005/README.md), and [006's reference-contamination challenge](../reference-006/README.md). The original `v0.4.0-rc4` release is untouched.

**Goal:** Make the lowest-cost legitimate physical test straightforward enough for an independent membrane laboratory to run. The actual product question is whether an early warning of fouling can be *more reliable and cheaper* than competent conventional pressure, flow, conductivity, temperature and impedance monitoring. We have no measured answer yet.

**Modular strategy:** Reuse the dry electronics and replace only the wet-exposed coupon/gasket cartridge. Three accessible S/R/G channels share a common class of coupon and housing features, so glass, coated-glass, ceramic and a non-deployable FR-4 control can be compared under matched conditions. We have **not established** that an independently protected G sees the same local water effects or stays clean.

## Actual work delivered

- [`cad/cartridge_geometry.py`](cad/cartridge_geometry.py): fully editable 92×82 mm *low-pressure review fixture* with 3 flow windows, replaceable coupon pockets, screw holes and asymmetric alignment locations. Generates viewable SVG and optional STEP solids (CadQuery). It is a **fixture concept**, not a production-ready pressure boundary.
- [`cad/generated/cartridge_plan.svg`](cad/generated/cartridge_plan.svg): inspection drawing; file is generated by the script.
- [`cad/generated/GEOMETRY_SCREEN.json`](cad/generated/GEOMETRY_SCREEN.json): explicit assumed tolerances. With nominal 1.00±0.05 mm gasket and 0.75±0.05 mm hard stop, modeled compression spans **15.79%–33.33%**. That does **not** demonstrate sealing. The gasket material, compressive stress, chemical compatibility and leakage remain unknown.
- [`cost/economics.py`](cost/economics.py): explicit **hypothetical** cost and lifetime model. It refuses to call economics proven without measured benefits and qualified quotes. The priority is affordable cartridge replacement and reader reuse, not an invented unit price.
- [`design/SCALING_DECISION.md`](design/SCALING_DECISION.md): realistic comparisons for electrode coatings, thermal substrates, fluidic cartridges and mixed deposits.
- [`design/MINIMUM_MEASURED_EVIDENCE.md`](design/MINIMUM_MEASURED_EVIDENCE.md): lab tests that can kill the invention quickly, conventional comparator and supplier gate.
- [`tools/readiness_gate.py`](tools/readiness_gate.py): machine-enforced **HOLD** on hardware/production claims; explicitly links 005 and 006 residual boundaries.

## Run

```bash
python3 cad/cartridge_geometry.py
python3 cost/economics.py
python3 -m unittest discover -s tests -v
python3 tools/readiness_gate.py
```

`cadquery` is optional for STEP geometry export; the SVG and checks use standard Python. No device is assembled or operated by this package. No physical measurement, pressure rating, lifetime, purchase quote, certification, manufacturing signoff, or realized water/energy savings is claimed.

## The cheapest possible product is allowed to be conventional

Do **not** force a 3-arm chip into production. Begin with a binary *actionable fouling alert* based on a calibrated conventional sensor stack. Add thermal sensing and then a protected third witness only if they independently improve false alarms or detection lead time under controlled, blinded mixed water chemistry. If they don't, save the complexity and report the loss.
