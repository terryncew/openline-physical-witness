# OpenLine Sensors — public research candidate 0.1

**Research / reproducibility release, not a validated performance release.**

Scope: one dependency-free, Python 3.10+ command-line instrument that audits user-supplied CSV water and energy totals, one transparent steady-state scenario model, two explicitly constructed datasets, and twelve independent negative/unit tests. No external calls, credentials, remote telemetry, actuation, hardware construction, or downloadable private research archives.

Tested: Python 3.13 normal and optimized mode, 12/12 tests each. No external hardware or facility data. Validated source file hash in each CSV audit result.

Deliberately excluded: 70.2% water savings as an OpenLine effect; $411,287 claimed earnings; 98.33% real-world fault identification; unattended cooling-system control; non-reproducible customer reports. Previous research findings remain exploratory until independently measured.

Review boundary: a clean environment running the README commands and an independent reviewer confirming the sample/fixture is clearly fictional. Once merged, this can be linked to the public as **free research software**, not a certified environmental solution.
